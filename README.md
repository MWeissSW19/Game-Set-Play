# Game, Set, Play
An interactive mini-game suite created for the Wimbledon Learning Programme.
Built as a Final Major Project for an MA in Interactive Media.

## Games
1. Batak reaction game
2. Jobs and careers quiz
3. Before & after history slider
4. Tennis equipment timeline
5. Build your planter box

## Tech
Built with HTML, CSS, and JavaScript using Claude as an AI-assisted design tool.
Designed for a Samsung 85" Flip touchscreen display.
